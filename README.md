# หนังสือ “สั่งดี” (Good Order Book / Living Will) 🕊️

> **มีสติ | มีความต้องการ | มีการวางแผน | เพื่อกลับคืนสู่ธรรมชาติอย่างสงบ**  
> *Mindfulness | Personal Will | Thoughtful Planning | For a Peaceful Return to Nature*

เว็บไซต์สร้างเอกสารแสดงเจตนารมณ์ล่วงหน้าในการปฏิเสธการรักษาที่ยืดการตายในวาระสุดท้ายของชีวิต (Living Will / Advance Directive) ตามมาตรา 12 แห่งพระราชบัญญัติสุขภาพแห่งชาติ พ.ศ. 2550

---

## 🌟 จุดเด่นของระบบ (Key Features)

- 🔒 **ความเป็นส่วนตัวและความปลอดภัย 100% (Client-side Only)**:  
  การประมวลผลและการสร้างไฟล์ PDF ทำงานบนเว็บเบราว์เซอร์ของผู้ใช้งานโดยตรง ไม่มีการส่งข้อมูล ไม่บันทึก และไม่มีฐานข้อมูลบนเซิร์ฟเวอร์ ข้อมูลจะถูกลบทันทีเมื่อปิดหน้าเว็บ
- 🌐 **ระบบ 2 ภาษาเต็มรูปแบบ (Bilingual Thai & English)**:  
  รองรับทั้งภาษาไทยและภาษาอังกฤษ พร้อมข้อกฎหมายและคำศัพท์ทางการแพทย์สากล
- 📄 **สร้างไฟล์ PDF คมชัดระดับ 300 DPI**:  
  สร้างเอกสารพร้อมพิมพ์ขนาด A4 จำนวน 10 หน้า ครบถ้วนทุกข้อเจตนารมณ์ ช่องลงลายมือชื่อผู้แสดงเจตนา ผู้มีสิทธิตัดสินใจแทน และพยาน
- 📱 **Mobile Responsive 100%**:  
  รองรับการใช้งานบนสมาร์ทโฟน แท็บเล็ต และคอมพิวเตอร์อย่างลื่นไหล
- 💸 **ไม่มีค่าใช้จ่ายตลอดชีพ (Free Forever)**:  
  โครงสร้างแบบ Static Web App ไม่มีค่าดูแลระบบเซิร์ฟเวอร์

## 📦 การนำขึ้นใช้งานออนไลน์ (Deployment)

### วิธีที่ 1: GitHub Pages (แนะนำ ง่ายและเร็วที่สุด)
1. เข้าไปที่แท็บ **Settings** ของ Repository บน GitHub
2. ไปที่เมนู **Pages** (แถบซ้ายมือ)
3. ใต้หัวข้อ **Build and deployment**:
   - Source: เลือก `Deploy from a branch`
   - Branch: เลือก `main` / `(root)`
4. กด **Save** ระบบจะสร้าง URL สำหรับเปิดใช้งานทันที เช่น `https://TB1456.github.io/good-order-book/`

### วิธีที่ 2: Render.com
1. เข้าสู่ระบบ [Render Dashboard](https://dashboard.render.com/)
2. กด **New +** -> เลือก **Static Site**
3. เชื่อมต่อกับ GitHub Repository นี้
4. ตั้งค่า:
   - **Name**: `good-order-book` (หรือชื่อตามต้องการ)
   - **Branch**: `main`
   - **Build Command**: เว้นว่างไว้
   - **Publish Directory**: `.` (จุด หมายถึง Root Directory)
5. กด **Create Static Site** เว็บไซต์จะออนไลน์พร้อมใช้งานทันที
